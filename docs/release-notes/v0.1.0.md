# Mithrandir integrations v0.1.0

The public integration kit now has a versioned JavaScript CLI, `mithrandir-connect`. Supply the gateway URL and Mithrandir key issued at [setup](https://mithrandir-production.up.railway.app/start), then run the command to list tools. It invokes an upstream tool only if you explicitly set `MCP_TOOL`.

The Release includes the CLI npm tarball and its SHA-256 checksum. [Install and verify the kit](https://github.com/Hyhyr2/mithrandir-integrations/blob/main/docs/releases.md), or use the source examples for JavaScript and Go.

This is a release of integration code, not the hosted Mithrandir server. Tests exercise a local authenticated MCP fixture, not a live customer gateway.
